# Check — jeu de cartes camerounais en ligne

Application web multijoueur en temps réel (Cloudflare + Supabase).

* Instructions pour Claude Code : `CLAUDE.md`
* Dossier technique complet : `docs/` (commencer par `docs/plan_de_developpement.md`)
* Base de données : `supabase/migrations/`

## Prérequis sur l'ordinateur

* Node.js 20 ou plus récent
* pnpm (`npm install -g pnpm`)
* Git
* Docker Desktop (plus tard, pour la base Supabase locale)
